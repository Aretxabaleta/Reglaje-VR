Mendizabala · Reglaje Mini Mill (prototipo)
Cómo se juega

1. Antes de nada, en la mesa auxiliar: bulón encima del taco de Z y bisel hasta que marque 0. 2. POWER UP con la puerta cerrada. 3. Con el palpador (T10, herramienta patrón, H10 = 0) toca la mesa con el reloj a 0 y haz PART ZERO SET en G59 Z. 4. Pon el taco en la mesa de la máquina y activa G59 en MDI (G59; INSERT, CYCLE START). 5. Herramienta por herramienta, empezando por el patrón: sobre el taco hasta 0, TOOL OFFSET MEASURE en OFFSET → Herrm y −50 ENTER. El patrón tiene que dar 0. Cambia con T1M06;. 6. Con el palpador coge G54 X−, Y− y Z en la pieza y activa G54 en MDI. VALIDAR.

Teclado: XYZ eje · I incremento · ←→ volante · A/D mantener = jog · ↑↓[] cursor · P PART ZERO SET · M TOOL OFFSET MEASURE · Enter agregar · F F1 · R RESET · Shift+Enter CYCLE START. En la pantalla MDI el teclado escribe y Enter = INSERT. Arrastra el volante con el ratón para girarlo. Pulsa sobre el taco, el bulón o la puerta para cogerlos o moverlos.

En las gafas: gatillo = pulsar o coger; mantén el gatillo sobre el volante y gira la muñeca; joystick izquierda/derecha = volante.
